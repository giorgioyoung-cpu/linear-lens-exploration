# Linear Lens Exploration

This repository explores least-squares affine approximations to transformer representations, motivated by the **J-lens** approach to language-model interpretability.

**[Go to the main project: `affine_lenses/`](./affine_lenses/)**

The `affine_lenses/` directory contains the current implementation, experiments, and documentation. Start with its [README](./affine_lenses/README.md).
